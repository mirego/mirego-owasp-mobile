# OWASP MASTG semgrep rules
This repository contains semgrep rules for the OWASP Mobile Application Security Testing Guide (MASGT) project tailored for Android and iOS applications.

## Usage
To use the rules, you can either use the [semgrep CLI](https://semgrep.dev/docs/introduction/) or the [semgrep GitHub Action](https://semgrep.dev/docs/integrations/github-action/).
